# 回复选项 · Reply Options 0.2.0

根据当前聊天生成 2–6 个带方向标签的回复选项，点击填入输入框，由你编辑和发送。

## 安装与更新

酒馆 → 扩展 → 安装扩展，粘贴：

https://github.com/agentgeleven-lab/sillytavern-reply-options

已安装用户在扩展管理中更新后刷新页面。旧版数量、聊天条数和填入方式会保留。默认折叠的“回复选项”位于输入框上方。

手动安装：解压后将文件夹放入 `data/<用户标识>/extensions/`，确保 manifest.json 直接位于扩展目录内。不要同时保留两份插件。兼容前端使用其实际用户数据目录。

## 新功能

- **可配置上下文**：读取当前用户人设、当前角色或群聊成员的描述、性格与场景。可单独关闭。
- **世界书参考**：可选读取本页最近一次 `WORLD_INFO_ACTIVATED` 事件中的实际激活条目，显示读取数量。刚刷新、切换聊天或修改相关资料后，需先正常生成一次角色回复。不是整本世界书，也不是本次重新扫描的结果。不开启时不传入。
- **自定义生成**：数量、最近消息条数、回复长度、纯对白/混合/动作形式、方向列表、自定义要求。
- **方向标签**：默认推进剧情、追问细节、委婉拒绝、自由发挥；可自行编辑。模型决定实际内容，方向与字数为提示词约束。
- **草稿扩写**：先在输入框写草稿或意图，点击“根据草稿扩写”；候选替换原草稿，可撤销。生成过程中修改草稿会阻止过时扩写覆盖。
- **候选切换**：追加模式保留原草稿，选择其他候选只更换插件填入内容，不不断堆叠。替换模式也能还原原草稿。
- **撤销与保留编辑**：撤销恢复填入前内容；用户修改后不会强制覆盖，点“保留编辑”将当前内容作为下一次选择的基础。
- **紧凑界面**：默认折叠，记住展开状态。设置放在扩展设置区域；若宿主缺少该区域，显示在面板内。“设置”按钮可展开并定位。
- **生成恢复**：等待上限 15–300 秒，默认 90 秒；支持停止等待、忽略迟到结果和重试。可以解析 JSON 前后解释、代码块和已闭合 think 块，仍严格校验有效选项。

## 数据范围与限制

只使用当前酒馆 `generateRaw` 模型连接，不新增服务或密钥设置。聊天文本最多 24000 字符（单条末尾 4000），用户人设 4000，最多 8 个群聊成员，每人设定最多 6000，世界书最多 10000，扩写草稿最多 6000，自定义要求最多 4000 字符。字符不等于 token，小上下文模型请减少条数或关闭部分来源。

角色卡读取描述、性格、场景，不包含全部卡片字段或图片。未加载的精简角色对象可能没有完整设定。世界书是最近实际激活快照，非本次完整提示词；宏内容以宿主事件提供的原文为准。宿主缺失人设/世界书接口时对应来源为空，状态栏显示数量。

“停止等待”和超时仅释放本插件界面，无法保证停止底层请求；可能仍计费。底层请求未结束时再次生成可能受模型服务或酒馆并发限制。插件不会调用全局停止接口来打断其他生成。

选项不写入聊天记录，不执行 HTML、斜杠命令或发送操作。切换聊天、编辑消息等会使旧候选失效。输入框被手动编辑时，撤销和换候选会保护现有文字。设置变化会要求重新生成。

## 开发接口

- `collectContext(ctx, settings, world)`：复制并截取聊天、人设、角色、世界书。
- `generateOptions(ctx, settings, {draft, world})`：当前模型生成，返回 `Promise<Array<{label,text}>>`。
- `parseOptions(raw, count)`：支持字符串数组及带 label/text 的 options 对象，去空、去重、限制长度。
- `DraftSelection`：维护原草稿及最后填入结果，实现切换/撤销/编辑冲突保护。
- `waitForResult(promise, ms, signal)`：等待上限和丢弃结果支持。
- `index.js`：宿主 UI 与事件协调；`style.css`：命名空间内样式；`manifest.json`：入口。

使用 `SillyTavern.getContext()`，兼容 `eventTypes` / `event_types`。需要标准 `#send_form`、`#send_textarea` 和支持对象参数的 `generateRaw`。

## 验证

运行 `node --test reply-options.test.mjs`。7 项自动化测试覆盖设置迁移、上下文开关、JSON 容错、草稿扩写提示、候选切换与编辑保护、超时取消、真实 UI 处理函数的会话切换与重试。另已通过 JavaScript 语法检查。

这些是模拟宿主验证，尚未在用户实际酒馆中验证界面布局、真实模型及世界书事件。实机请检查：正常生成 → 换候选 → 撤销 → 手动改字 → 保护提示 → 草稿扩写 → 切换聊天 → 世界书读取数量。

禁用/卸载后刷新页面即可。不会修改原有聊天、角色卡或世界书文件。
